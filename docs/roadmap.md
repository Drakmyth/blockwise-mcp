# Roadmap

This roadmap tracks future work only. `Sooner` is ordered by relative priority; `Later`, `Investigate`, and `Deferred` are unordered. Investigation work moves to `Sooner` when the project is ready to drive it. Completed work is removed rather than archived here.

## Sooner

Ordering is still to be decided.

- Component-bearing item and recipe outputs
- Smithing recipes
- Fabric loader support
- First-release installation, configuration, usage, and compatibility documentation

## Later

- Cooking experience and processing duration in recipe contracts and MCP output
- Loaded-mod dependency and source metadata
- Quilt loader support
- Forge loader support
- In-game endpoint controls and startup retry

Additional MCP tools will be added here as individual entries after their scope is identified.

## Investigate

- Custom and dynamic recipe semantics
- Dedicated-server and multiplayer lifecycle
- MCP protocol version for the first release
- Production-line optimization

## Deferred

- Offline modpack inspection
- Public or remote network access
- Runtime categories beyond loaded mods and recipes
