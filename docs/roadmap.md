# Roadmap

This roadmap tracks future work only. `Sooner` is ordered by relative priority; `Later` and `Deferred` are unordered. Completed work is removed.

## Sooner

1. Fabric loader support
2. Dedicated-server and multiplayer lifecycle
3. Production-ready documentation and automated release generation

## Later

- Recipe ingredient/output data components
- Smithing recipes
- Recipe experience rewards and processing durations
- Quilt loader support
- Forge loader support
- In-game MCP configuration and manual retry of failed MCP startup
- Custom/modded recipe types
- Dynamic recipes (e.g. dyes, potions, armor trim)
- `get_item`: retrieve one item by exact ID
- `search_items`: search items with strictly narrowing AND filters

- `search_blocks`: search blocks with strictly narrowing AND filters
- `get_recipe`: retrieve one recipe by exact ID
- `search_recipes`: search recipes with strictly narrowing AND filters
- `get_tag`: retrieve one tag by exact ID

- `get_mod`: retrieve one loaded mod by exact mod ID
- `search_mods`: search loaded mods with strictly narrowing AND filters
- `get_fluid`: retrieve one fluid by exact ID
- `search_fluids`: search fluids with strictly narrowing AND filters
- `get_enchantment`: retrieve one enchantment by exact ID
- `search_enchantments`: search enchantments with strictly narrowing AND filters
- `get_effect`: retrieve one effect by exact ID
- `search_effects`: search effects with strictly narrowing AND filters

- `get_dimension`: retrieve one dimension by exact ID

## Deferred

- Serverless/Offline MCP availability
