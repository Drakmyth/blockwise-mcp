# Minecraft Registry MCP

An MCP server for querying authoritative runtime data from modded Minecraft.

## Status

Early discovery and design. No runnable artifact is available yet.

## Initial scope

- NeoForge for Minecraft 1.21.1
- Integrated single-player
- Loaded mod listing
- Recipe lookup by output item ID
- Localhost-only MCP access

See [project discovery](docs/discovery.md) for current decisions, risks, and open questions.
